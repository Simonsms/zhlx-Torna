# 提供功能导航搜索与快捷键

## 目标

在不新增后端搜索能力的前提下，让用户通过顶部入口和键盘快速查找并打开控制台功能。

## 范围

- 建立可测试的前端导航命令注册表。
- 支持标题、别名和关键词匹配。
- 使用现有权限和当前空间/项目上下文过滤结果。
- 选择结果后通过现有路由打开，并由登录态工作 Tab 接管。
- 提供明确且不与浏览器常用快捷键冲突的唤起方式。

## 验收标准

- [ ] 顶部搜索入口和键盘快捷键均可打开命令搜索。
- [ ] 搜索首页、项目成员、常量管理、发布管理等关键词能得到正确入口。
- [ ] 普通成员看不到无权限的管理员命令。
- [ ] 缺少项目上下文时不生成依赖 `projectId` 的无效路由。
- [ ] 结果选择后打开或复用正确工作 Tab。
- [ ] 匹配、权限过滤和上下文过滤具有单元测试。

## 验证重点

确认搜索完全基于前端已有路由和状态，不新增请求，不把“功能搜索”描述成“文档全文搜索”。
