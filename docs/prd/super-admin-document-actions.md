# 超级管理员文档操作入口

## Problem Statement

浏览模式会通过 `showOptBar` 隐藏文档操作栏，导致超级管理员无法查看文档变更历史或下载文档。权限接口已经提供 `isSuperAdmin`，但文档渲染器尚未使用该状态控制这两个入口。

## Solution

浏览模式下复用现有超级管理员权限状态：当 `isSuperAdmin === 1` 时显示“变更历史”和“下载”入口；普通用户保持现状。管理模式原有操作栏行为不变。

## User Stories

1. 作为超级管理员，我希望在浏览标准接口文档时查看变更历史，以便审计文档修改。
2. 作为超级管理员，我希望在浏览标准接口文档时下载文档，以便离线使用。
3. 作为超级管理员，我希望在浏览自定义或 Markdown 文档时使用相同入口，以便不同文档类型行为一致。
4. 作为普通用户，我希望浏览模式继续隐藏管理入口，以免看到无权限操作。
5. 作为管理模式用户，我希望现有操作栏保持不变，以免发生功能回归。

## Implementation Decisions

- 复用权限初始化后挂载到 Vue 实例的 `isSuperAdmin()`，不重复请求权限接口。
- 仅放宽“变更历史”和“下载”两个入口；代码生成、常量查看等其他操作仍由原操作栏状态控制。
- 同时覆盖标准接口文档与自定义/Markdown 文档渲染器。
- 使用严格的布尔显示逻辑兼容接口返回的数值 `1`。

## Testing Decisions

- 组件测试只断言用户可见行为，不依赖 Vuex 内部实现。
- 分别覆盖超级管理员浏览模式、普通用户浏览模式、管理模式三个边界。
- 覆盖标准接口文档与自定义/Markdown 文档组件。

## Out of Scope

- 修改 `/user/perm/get` 契约或权限初始化流程。
- 向普通项目管理员开放入口。
- 改造其他文档操作或重新设计按钮样式。
- Vue 3 升级相关修改。
